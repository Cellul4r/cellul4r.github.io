# Competitive programming

Route components remain in `src/pages`; routing is configured in `src/app/router.tsx`.

- `overview/`: introduction, contest list, and tutoring section.
- `contests/`: contest cards and photo galleries.
- `matching/`: graph generation, max-flow solver, and Anya playback.
- Shared styles live in `src/styles/globals.css`.

Run `npm run test:matching` and `npm run build` to validate the existing experience.
